# B-LS-9252-24V

基于 STM32 + LAN9252（EtherCAT 从站控制器）的开发板，面向 EtherCAT 从站接入与 DI/DO 信号转接场景，是从站协议方案的参考设计载体。当前为规划中的骨架文档，功能与参数以定型为准，未定型处标注 TBD。

> 状态：规划中（骨架文档，功能与参数以定型为准）｜文档更新：2026-10-27｜未定型处标注 TBD
